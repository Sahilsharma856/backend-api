# 📝 Blog API Backend (Express + Prisma + PostgreSQL)

This is a simple blog API built using **Express.js**, **Prisma ORM**, **PostgreSQL**, **JWT authentication**, and **Zod** for request validation.

---

## 🔧 Features

- ✅ User Signup & Login with hashed passwords
- ✅ JWT-based authentication middleware
- ✅ Create and view blog posts (only for authenticated users)
- ✅ Prisma for database modeling and access
- ✅ Zod for validating user inputs
- ✅ PostgreSQL database with Neon (cloud DB)

---

## 📦 Technologies Used

- **Express.js** – Server framework
- **Prisma** – ORM for PostgreSQL
- **PostgreSQL** – Database
- **Zod** – Schema validation
- **JWT** – Authentication
- **bcrypt** – Password hashing
- **dotenv** – Environment variable management
